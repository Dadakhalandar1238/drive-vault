Before you connect another drive

Every drive you connect goes through the same Google Cloud project as your primary sign-in. While that project's OAuth consent screen is still in Testing mode, the Google account you're about to add has to be listed there as a Test user — otherwise Google blocks the sign-in with an access-denied error before it ever reaches this app, and there's no way for Drive Vault to add it for you automatically (Google doesn't offer an API for that).
